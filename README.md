# AREES EL GANNAH (عريس الجنة)

Single-file Three.js Egyptian comedy runner game.

- Deployed files (root): `index.html` (minified build), `assets/`, `icons/`, `sw.js`, `manifest.webmanifest`
- `source/index.source.html` — un-minified source of the game
- `source/tools`, `source/characters` — authoring tools and character data
- `promo/` — promo video draft
- `.vercelignore` keeps `source/` and `promo/` out of the deployment
